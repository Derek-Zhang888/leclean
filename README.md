# 乐清理 · LeClean

> **v1.0** · Windows 便携版 · 免安装 · 只读扫描 · 删除走回收站可恢复

**乐清理** 是一个 Windows 磁盘空间清理工具。它扫描本机所有磁盘分区的顶层母文件夹，统计占用、
判定来源、核对注册表关联、给出删除风险等级，支持一键清理（移入回收站）、文件占用诊断与分级解除，
以及缓存目录清理、已装软件清单、快照对比等专项分析。

- 作者：**Derek888**（[@Derek-Zhang888](https://github.com/Derek-Zhang888)）
- 仓库：<https://github.com/Derek-Zhang888/leclean>

## 一、准备引擎（必读）

乐清理依赖 **WizTree** 作为磁盘扫描引擎，**本仓库不附带 WizTree**，需要你自行下载放置：

1. 到 WizTree 官网下载免费个人版：<https://diskanalyzer.com>
2. 解压后，把其中的 **`WizTree64.exe`** 放进程序目录的 **`WizTree\`** 子文件夹里
   （即 `乐清理\WizTree\WizTree64.exe`）。

> 原因：WizTree 许可为「仅限个人使用」，随软件打包分发需另行购买 Distribution License，
> 所以本程序只负责调用、不打包它。
>
> 也可以不手动放：程序会自动在常见安装位置、注册表记录中查找，或用环境变量
> `WIZTREE_PATH` 指定路径。

## 二、使用方法

### 方式 A：下载便携版（推荐）

1. 下载便携版压缩包，解压得到 **`乐清理`** 文件夹。
2. 按上一步把 `WizTree64.exe` 放进 `乐清理\WizTree\`。
3. 双击 **`乐清理.exe`** 运行。

整个文件夹拷到 U 盘也能跑，**无需安装 Python、不写注册表、不留残留**。

### 方式 B：源码运行 / 自行打包

```bash
pip install pywebview pyinstaller

# 直接运行（开发）
python -m app.main

# 打包便携版（产出 dist\乐清理\ 文件夹）
python build.py
```

> 依赖系统 **WebView2 运行时**（Windows 11 自带；Windows 10 1803 以上绝大多数已自带，
> 缺失时安装微软官方免费的 WebView2 Runtime 即可）。

## 三、主要功能

### 扫描模块
- 自动枚举本机全部分区与物理磁盘（盘符 / 卷标 / 文件系统 / 容量 / 可用）
- 扫描各盘**顶层母文件夹**，一并扫描**缓存 / 临时目录**（Temp、更新缓存、浏览器缓存等）
- 来源判定、注册表关联核对、删除风险分级，每一条都有**可解释的判定依据**
- 表格按名称 / 大小 / 修改日期 / 风险等级排序，可按来源、风险筛选，按名称搜索

### 清理模块
- 按风险分组（缓存 / 系统更新残留 / 疑似残留 / 低风险 / 中风险 / 高风险 / 禁删）
- 每组独立「全选本组」、可展开收起；组内表头可按大小 / 风险 / 名称排序
- **一键清理**：批量移入系统回收站（可还原），带**实时进度条**
- **删除失败跳过继续**：遇错误不再中止整批，清完其余并标注失败原因
- **母目录删不掉时降级清空子目录**：若某文件夹因占用删不掉，自动尝试逐个删除其一级子文件夹
- 每行右键：定位目录 / 复制路径 / 查看谁占用并解除 / 加入白名单
- **文件占用诊断与分级解除**（基于 Windows Restart Manager API，无需第三方工具）：
  延迟到重启后删除 / 重启占用进程 / 结束占用进程，每档二次确认，系统关键进程硬保护

### 软件清单
- 读取注册表 4 个 Uninstall 键 + App Paths，列出已安装程序
- 自动分「应用 / 系统组件」两类，可查看版本 / 发行商 / 占用 / 安装时间 / 安装目录，并一键走正规卸载

### 其它
- 快照对比：本次 vs 上次，标出增长最快 / 缩小 / 新增 / 消失的目录
- 关闭行为可配置（每次询问 / 最小化到托盘 / 直接退出）
- 操作提示音（开始/结束扫描、开始/结束清理，可开关）
- 关于作者页（含版本号、引擎、安全承诺）

## 四、⚠️ 权限与删除失败说明（重要）

有些文件/文件夹**可能无法被删除**，常见原因：

- **权限不足**：部分系统目录、受保护目录需要**管理员权限**才能删除；非管理员运行时删除会失败。
- **文件被占用**：目标文件或子文件夹正被某个程序、服务、杀毒软件打开/锁定，删除会被拒绝。

本工具内置了「占用诊断与解除」能力，能处理**大多数**普通占用；但对于

- 内核级锁、杀软驱动占用的文件
- 需要更高权限的系统级目录

本工具**可能仍然删不掉**（会如实标注失败原因，绝不静默假装成功）。

**这类情况建议配合高权限工具一起使用**，例如：

- **火绒安全** 的「文件粉碎」「解除占用」功能
- Windows「安全模式」下删除
- 以**管理员身份运行**本程序（部分受保护目录可删）

> 提醒：删除任何文件前请确认其用途。删除系统关键文件或正在使用的程序文件可能导致系统或软件异常。

## 五、安全底线（写死在代码里）

- **默认只读**：扫描阶段不做任何修改。
- **删除仅走系统回收站**，可随时还原；不提供永久删除。
- **系统关键目录硬锁定**：盘根、`Windows`、`Program Files`、`ProgramData`、`Users`、
  `Recovery`、`System Volume Information`、`$Recycle.Bin`、`$Extend` 等永远无法勾选。
- **白名单**：加入白名单的目录同样硬锁定。
- **二次确认**：一键清理前弹出危险警告，并逐条列出将被删除的路径。
- 数据全部落在程序目录 `data\` 下（快照、报告、配置、白名单），**不写注册表、不写 AppData**。

## 六、已知限制

- 默认打包为 **onedir（文件夹）**而非单文件 exe：启动更快（约 1.3 秒）、退出无残留。
  单文件模式可用 `python build.py onefile` 构建，但启动更慢、退出可能残留十几秒。
- 「延迟到重启后删除」需管理员权限（要写系统会话管理器键），非管理员会失败并如实提示。
- 占用诊断依赖 Restart Manager，**少数内核级锁（如杀软驱动）不一定能列出**；
  此类情况请参照「四、权限与删除失败说明」配合火绒等工具处理。
- 清理的取消粒度是「项目之间」：底层 `SHFileOperationW` 是一次阻塞调用，
  无法在单个大目录删除中途打断。
- 请勿用任务管理器「结束任务」反复强杀进程：会让 WebView2 子进程变成孤儿，
  占住临时目录、影响后续启动。正常点「✕」关闭不会有此问题。
